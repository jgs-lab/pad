# PAD

Software tools for collecting and analyzing affective responses using the
**Pleasure–Arousal–Dominance (PAD)** model of emotion.

The project was developed to support experiments in which participants'
affective responses to visual stimuli were collected and compared with
expected emotional responses.

## Overview

The PAD model represents affect using three dimensions:

- **Pleasure** — positive versus negative emotional experience
- **Arousal** — level of activation or stimulation
- **Dominance** — sense of control or influence

This repository contains experimental software for processing PAD measurements,
analyzing responses over time, and comparing participant responses with
expected values associated with video stimuli.

## Repository Contents

The project includes:

- Java-based PAD data analysis
- A graphical user interface for working with experimental data
- Statistical analysis of PAD values
- Video timing and reference data
- Web-based components used for PAD validation
- Supporting scripts and interface files

The analysis software calculates statistics such as averages and standard
deviations across the PAD dimensions and supports comparisons between observed
and expected affective responses.

## Research Context

This repository represents an earlier research effort exploring computational
methods for modeling and analyzing human affect.

It is preserved as part of the research software collection of the
**JGS Laboratory** and may also serve as a reference for newer work involving
affective computing, human sensing, and adaptive intelligent systems.

## Status

This is a legacy research project preserved for reference and continued
experimentation. Some dependencies and implementation choices reflect the
software environment in which the project was originally developed.
